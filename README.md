# 흉기 신고 현장대응 통합 매뉴얼

흉기 관련 112 신고의 접수부터 출동, 현장 통제, 구호, 체포, 증거 확보, 경찰서 인계, 사후관리까지를 하나의 흐름으로 정리한 매뉴얼 초안입니다. 현장 경찰관, 112상황실, 현장책임자가 같은 문서를 함께 씁니다.

> **이 문서는 경찰청의 공식 매뉴얼이 아닌 검토용 초안입니다.** 법령 기준일은 2026. 11. 6.입니다. 내부지침 등 확인되지 않은 사항은 [부록 F](MANUAL.md#부록-f--공식-제정-전-확인-사항)에 정리했습니다. 실제 적용 전 법무·내부 검토가 필요합니다.

## 보는 방법

| 파일 | 용도 |
|---|---|
| [`index.html`](index.html) | 현장용 화면. 휴대전화·PC 브라우저에서 열면 인터넷 없이 작동합니다. |
| [`MANUAL.md`](MANUAL.md) | 매뉴얼 원본. GitHub에서 바로 읽을 수 있습니다. |

`index.html` 기능: 역할별 보기(현장·상황실·지휘관), 단계 목차, 검색, 체크리스트 저장, 야간 화면, A5 인쇄. 체크 내용은 사용하는 기기의 브라우저에만 저장되고 외부로 전송되지 않습니다. 사건 정보나 개인정보는 입력하는 곳이 없습니다.

## 구성

- **신속카드**: 전체 흐름, 무전 순서, 체포 고지 5항목, 권총 사용 전 확인, 시한
- **0~10단계**: 각 단계마다 ① 현장 경찰관 ② 112상황실 ③ 현장책임자 ④ 법적 근거 ⑤ 금지사항 ⑥ 무전 예시 ⑦ 완료 확인
- **상황별**: 주택, 상가, 지하철, 학교, 도주, 자해 위험, 인질, 외국인·소년·장애인
- **부록**: 시한표, 3권 체계, 교육·평가, 죄명표, 근거 법령, 확인 필요 사항

## 수정 방법

내용은 `MANUAL.md`만 고칩니다. 그다음 아래 명령으로 화면을 다시 만듭니다. Python 3 외에 설치할 것은 없습니다.

```
python build.py
```

0~10단계에 ①~⑦ 항목 중 하나라도 빠지면 빌드가 실패합니다. 법령 개정 시 부록 E의 번호와 시행일도 함께 갱신합니다.
