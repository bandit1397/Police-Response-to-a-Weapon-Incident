# 흉기 신고 현장대응 통합 매뉴얼

흉기 관련 112 신고의 접수부터 출동, 현장 통제, 구호, 체포, 증거 확보, 경찰서 인계, 사후관리까지를 역할별 업무 흐름도로 정리한 매뉴얼 초안입니다.

> **이 문서는 경찰청의 공식 매뉴얼이 아닌 검토용 초안입니다.** 법령 기준일은 2026. 11. 6.입니다. 내부지침 등 확인되지 않은 사항은 `MANUAL.md`의 '확인 필요 사항'에 정리했습니다. 실제 적용 전 법무·내부 검토가 필요합니다.

## 보는 방법

| 파일 | 용도 |
|---|---|
| [`index.html`](index.html) | 현장용 화면. 휴대전화·PC 브라우저에서 열면 인터넷 없이 작동합니다. |
| [`MANUAL.md`](MANUAL.md) | 매뉴얼 원본. GitHub에서 바로 읽을 수 있습니다. |

첫 화면에서 역할을 고르면 그 역할의 업무 흐름도만 나타납니다.

- **칸을 누르면** 체크리스트, 금지사항, 무전 예시, 근거 조문이 펼쳐집니다.
- **판단 칸**의 답을 누르면 해당 칸으로 이동합니다.
- **체크를 모두 마친 칸**은 번호가 초록색으로 바뀝니다.

현장 직원 화면 아래에는 **출동 음성 메모**가 있습니다. 사건위치, 인상착의, 도주경로 버튼을 눌러 각각 최대 60초까지 녹음하고, 다시 누르면 바로 들을 수 있습니다. 음성은 화면이 열려 있는 동안만 기기 메모리에 있고, 저장되거나 외부로 전송되지 않으며 화면을 닫으면 삭제됩니다. AI 음성 인식은 넣지 않았습니다. 공식 기록이 아니며, 실제 사용 전 법무·보안 검토가 필요합니다.

그 밖에 전체 검색, 야간 화면, A5 인쇄를 지원합니다. 체크 내용은 사용하는 기기의 브라우저에만 저장되고 외부로 전송되지 않습니다. 사건 정보나 개인정보를 글자로 입력하는 곳은 없습니다.

## 구성

| 역할 | 흐름 |
|---|---|
| 현장 직원 | 근무 준비 → 착용 → 이동 → 도착 → 통제 → 구호 → 체포 → 증거 → 호송·인계 → 종결 |
| 현장 책임자 | 근무 관리 → 지휘 개시 → 현장 지휘 → 물리력 지휘 → 체포 확인 → 증거 지휘 → 호송 지시 → 사후조치 |
| 112상황실 | 근무 준비 → 접수 → 코드 → 지령 → 전파·공동대응 → 광역 공조 → 보고 관리 → 종결 |
| 수사부서 | 인수 → 통지 → 시한 → 특별 대상자 → 유치 → 증거·영상 → 피해자 보호 |

여러 역할이 함께 보는 물리력 기준, 체포 고지, 시한표, 죄명표, 근거 법령 등은 '참고'에 한 번만 두고 각 칸에서 링크로 연결합니다.

## 수정 방법

내용은 `MANUAL.md`만 고칩니다. 그다음 아래 명령으로 화면을 다시 만듭니다. Python 3 외에 설치할 것은 없습니다.

```
python build.py
```

작성 규칙은 `build.py` 맨 위에 있습니다. 갈림길이나 링크의 대상이 없으면 빌드가 실패합니다. 법령 개정 시 '근거 법령'의 번호와 시행일도 함께 갱신합니다.
